# /public/images

Drop these files here (exact names matter):

- `profile.png` — your hero portrait
- `projects/siddique-ai.png` — Siddique-AI screenshot/mockup
- `projects/dripvault.png` — dripVault screenshot/mockup
- `projects/task-api.png` — Secure Task API screenshot (e.g. Swagger UI)

Until a file exists at the expected path, the site automatically renders an
elegant "IMAGE PLACEHOLDER" block instead of a broken image — nothing on the
page will ever break because an image is missing.

See `CUSTOMIZATION.md` at the project root for full instructions.
